# src/test/resources/legacy/v1 - reference history files

Generated by `tools/baseline/Baseline.java` (see `tools/baseline/README.md`); do not edit by hand.
Each file is a `history.tsv` as the application could find it on disk. The bytes are fixed and must not change.
`.gitattributes` in this folder disables line-ending conversion so the CRLF and BOM files stay byte-exact.

Behaviour OBSERVED when the current code loads each file: the file is copied to a temporary folder, then loaded
by `FileCalculationHistoryStore` (counts) and by a `CalculatorPresenter` built on it (status message and entries).
Format of the files: optional `#calc-history v1` header, then one line per calculation with 4 tab-separated columns:
`Operation` constant name, first operand, second operand (empty for a root), result.
